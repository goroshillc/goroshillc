### What I ship

Operations software for a family restaurant and property business. I set the requirements and direct the work; the software is built with AI assistance, and I accept each result against measured checks.

| Outcome | Measured result |
| --- | --- |
| Receipt reading | Totals read correctly on a held-out set of 91 receipts went from 51 to 91. |
| Document search | Finds 83% of the relevant documents within the first ten results, on 40 labelled questions. |
| Crew visit reports | Property crew visits recorded automatically; an independent recount matched exactly. |
| Month-end reporting | Close and owner reports for four separate sets of books; a monthly report matched an independent count to the cent. |

Business records and the code behind them stay private.
